# Sample End-to-End Run

## Query

What are the key principles of accessible user interface design?

## Agent Workflow

### Planner

1. Identify the main HCI concepts in the query: accessible user interface design.
2. Review authoritative design guidance and recent practice-oriented sources.
3. Extract 3-5 key principles, then summarize them with citations and practical implications.

### Researcher

1. Designing for Accessibility: Inclusive UX/UI Principles - Ironhack  
   <https://www.ironhack.com/us/blog/designing-for-accessibility-inclusive-ux-ui-principles>
2. Accessibility overview - Material Design 3  
   <https://m3.material.io/foundations/overview/principles>
3. UI design principles - Maze  
   <https://maze.co/collections/ux-ui-design/ui-design-principles/>

### Writer

Accessible user interface design is crucial for ensuring that all users can navigate, understand, and interact with digital products. This requires designers to consider the diverse abilities and needs of their users.

Key principles include designing with and for users in mind, treating accessibility as a default requirement, providing clear and consistent navigation, supplying alternative text and descriptions, and using color carefully so interfaces remain understandable for people with color-vision differences.
